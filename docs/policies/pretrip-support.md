# 共享出行出行前服务规则（合成）

适用于共享电单车出行前的路线、费用和停车提示演示。具体城市规则以当地主管部门和运营区域公告为准。

## 费用预估

路线距离和预计时间可以由地图服务提供，但共享出行最终费用应由 RideOps 的计价规则计算。预估费用不包含优惠券、套餐折扣、临时活动或订单结束后的异常费用，客服不得把预估值表述为最终扣款。

## 停车与还车

用户应在允许停放区域结束订单，并确认车辆锁闭和订单已结束。地铁出入口、消防通道、盲道、机动车道和其他明确禁停区域不应作为还车点。城市和运营区域可能设置不同的电子围栏，无法确认时应提示用户查看应用内停车范围。

## 路线限制

地图路线只表示路径和时间估计，不代表所有路段都允许共享电单车通行。用户应遵守当地交通规则、道路禁行和临时管制；最终路线和通行条件以现场标志及实时交通信息为准。
